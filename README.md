# Dyrity Webforge

Site institucional autoral da Dyrity Webforge, criado em HTML, CSS e JavaScript puro.

## Rodar localmente

```bash
python -m http.server 8000
```

Depois acesse `http://localhost:8000`.

## Estrutura

- `index.html` — conteúdo e estrutura semântica
- `style.css` — design system, responsividade e animações
- `script.js` — menu, scroll reveal, cursor e navegação
- `assets/` — logo oficial e fotos dos founders
